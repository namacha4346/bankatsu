# 「伴活」プロジェクト 辛口評価レポート

評価者視点:婚活パーティー・街コン・コミュニティイベント数百本の企画運営経験を持つイベントプロデューサーとして

---

## 1. 総合評価:4.5 / 10

**一言サマリー:「ブランド設計は上位5%の出来。事業設計は0点。つまり、まだ『商品』が存在しない。」**

ブランドブックの完成度、トーン&ボイスの一貫性、「伴=人+半」の言語資産化——ここまで丁寧に世界観を作れる立ち上げ案件は正直めったに見ません。文章のプロが書いたレベルです。

しかし、イベント事業として見ると**「いつ・どこで・いくらで・誰が・何人でやるのか」が全部未定**。ホームページは美しい空箱で、CTAのLINEすら「準備中」。この状態は「ブランドはあるが商品がない」状態であり、私の経験則で言えば**この手の案件の8割は、世界観づくりが楽しくなりすぎて第1回イベントに到達する前に失速します**。点数の低さはコンセプトの否定ではなく、「実行の設計がゼロ」に対するものです。

## 2. このコンセプトで実際に集客できるか

### 結論:**「そのままでは集客できない。ただし、鉱脈自体は本物」**

### 2-1. ターゲットの行動心理 — ここに致命的な矛盾がある

現場で20年見てきた30〜40代独身者の行動原理はシンプルです。

**「重いのは嫌だが、出会いの『確率』が担保されていない場に、金と休日は使わない。」**

引き継ぎ書は「恋人を探しに来ました、ではなく、なんか楽しそうだから来てほしい」と言う。気持ちは分かりますが、**「なんか楽しそうだから」で休日に単独で新規イベントに来る30〜40代は、母集団の中のごく少数派**です。この年代は可処分時間が最も貴重な層で、参加判断は「投資対効果」で行われます。彼らが払っているのは参加費ではなく**「日曜の午後」という機会費用**です。

そして残酷な現実を言うと——**このコンセプトに反応して申し込む人は、ほぼ全員「本音では出会い目的」です。**「恋愛は目的じゃない」という建前が心理的な言い訳(アリバイ)として機能するから来るのであって、本当に出会いに興味がない人は普通の趣味サークルかストアカに行きます。これは悪いことではありません。むしろ**このブランドの本当の商品は「出会い目的で来ることの気まずさの除去」**です。運営側がそれを自覚しているかどうかで、設計の精度が全く変わります。ブランドブックはやや「建前を真に受けている」節があり、そこが危うい。

### 2-2. 競合との集客力比較

| 競合 | 集客上の武器 | 伴活が勝てるか |
| --- | --- | --- |
| 既存婚活パーティー(PARTY☆PARTY等) | 「男女比保証」「マッチングシステム」「駅前会場」「毎日開催」という圧倒的な確実性 | **確実性では絶対に勝てない。**勝ち筋は「あそこには行きたくない層」の受け皿のみ |
| 趣味コン(街コンジャパン系) | 「趣味×出会い」を明言。伴活のイベント内容とほぼ同じ(料理コン、ボドゲコン、焚き火コンは既にある) | **コンテンツでは差別化できていない。**差は「出会いを明言しない」ことだけ。これは集客上はハンデにもなる |
| オフ会・社会人サークル(つなげーと、ジモティー等) | 無料〜1,000円台。数が膨大 | 価格勝負になったら負け。「男女比と真剣度の管理」で差別化するしかない——が、それを打ち出すと婚活っぽくなるジレンマ |

つまり伴活のポジションは**「趣味コンの体験内容 × 婚活の安心管理 × サークルの空気感」のいいとこ取り**であり、それ自体は成立し得ます。ただし「いいとこ取り」は裏返すと**「どのカテゴリの検索にも引っかからない」**ということ。「婚活 パーティー 40代」で検索する人にも「ボードゲーム会 東京」で検索する人にも届きません。新語ブランドの宿命です。

| チャネル | 現実的な見込み | コメント |

| ポータル掲載(街コンジャパン、こくちーず、Peatix) | **5〜15人** | 最も現実的。ただし「出会い」と書かないと集まらず、書くとブランドが濁る。ここが最初の踏み絵 |

## 3. 構造的な問題点

### 問題① 男女比の担保 — 最大のアキレス腱

「出会いを目的にしない」建前と「男女比管理」は構造的に衝突します。婚活パーティーが男女比を保証できるのは、男女別料金・男女別受付・定員管理をシステムでやっているからです。伴活が「参加する人」として性別を問わず募集すれば、**私の経験上ほぼ確実に男7:女3か、逆に女性ばかりに偏ります**(コンテンツ次第。ボドゲ・焚き火は男に、料理・散歩は女に寄る)。男女比が崩れた回は満足度が崩壊し、「また来たい率」というKPIが即死します。ブランドブックはこの問題に一行も触れていません。**引き継ぎ書の優先順位②に「男女比」とあるのに、未着手のままHPを公開しているのは順序が逆です。**

### 問題② 鶏卵問題 — 実績ゼロ・写真ゼロ・顔ゼロ

30〜40代がイベント参加前に必ず確認するのは「過去回の様子(写真)」「参加者の雰囲気」「主催者が何者か」の3点です。現状すべてゼロ。特に**主催者の顔が見えない出会い系イベントは、女性参加者の警戒レベルが最大になります**。「遊び目的お断り」と書いてあっても、主催者が匿名なら「主催者自身が遊び目的では?」と疑われるのがこの業界の常識です。

### 問題③ 「遊び目的お断り」に実効性がない

FAQに「お断りしています」と書くだけでは何のスクリーニングにもなりません。遊び目的の人間は自分を遊び目的と申告しません。現状は**「悪意ある参加者へのフィルタがゼロのまま、『安全な場』を約束している」**状態で、これは約束違反のリスクを主催者が全額背負っているのと同じです。一件のトラブル(しつこい連絡先要求、イベント外での付きまとい)で、女性リピーターは全滅し、口コミで再起不能になります。出会い系イベントの死因の第1位はこれです。

### 問題④ 価格設定の不在 — 「価格はスクリーニングである」という視点の欠落

料金はどこにも書かれていない。イベント業において**価格は収益装置である前に、来場者の質を決めるフィルタ**です。無料〜1,000円なら冷やかしと遊び目的が混入し、8,000円超なら「婚活価格」に見えてコンセプトと矛盾する。この設計を後回しにしているのは、事業として最重要の意思決定から逃げているのと同じです。

### 問題⑤ 「連絡先交換を迫らない」設計は、満足度の時限爆弾

理念としては美しい。しかし参加者の本音は出会いです(前述)。「いいなと思う人がいたのに、連絡先も交換できず、次いつ会えるかも分からないまま帰った」——この体験は**当日満足度は高いのに、翌週「で、何も残らなかったな」に転化します**。「また会う口実はこちらで用意します」とHPは言うが、その口実(次回イベント)の日程が存在しない現状では、**再会の確率は実質ゼロを約束しているのに等しい**。「急がせない」と「機会を奪う」は別物です。ここの仕組み(相互希望マッチング等)がないと、リピート率という生命線のKPIを自分で殺します。

### 問題⑥ 「初参加が一番居心地いい」×「リピート設計」の内部矛盾

「また来たい」をKPIにしながら「常連の内輪化を許さない」。この両立は口で言うほど簡単ではありません。リピーターが増えるほど場は内輪化し、内輪化を防ぐためにリピーターを冷遇すればリピート率が下がる。**常連に「役割」を与える運営設計がない限り、この理念は3回目の開催で破綻します**。ブランドブックは「判断基準」は書いたが「運営手順」を書いていない。

### 問題⑦ 体験コンテンツの運営難易度を舐めている

料理(会場費・食材・衛生管理・包丁=リスク)、焚き火(火気・場所・天候・保険)、散歩(公道の引率・雨天中止)——**列挙されている体験は、着席パーティーの3〜10倍の運営コストとリスクを持つ種目ばかり**です。初回からこれをやると、出会いの設計に割く運営リソースが残りません。

### 問題⑧ 「伴活という文化を作る」という目標が、目の前の1回目を軽くしている

「婚活・就活・終活と並ぶ言葉に」——志は買います。が、私の経験では**「文化を作る」と言い出したプロジェクトほど、目の前の20人を満足させる泥臭い仕事を後回しにします**。文化は100回目のイベントの副産物であって、戦略ではありません。

## 4. 改善案

### 4-1. 【最重要】第1回イベントを成立させる方法 — 最初の20人の集め方

原則:**第1回は「集客」ではなく「キャスティング」と考える。**公募で埋めようとした時点で失敗です。

**目標構成:20人(男10:女10)、うち公募枠は最大6人。**

1. **主催者本人と運営チームの直接声かけで12〜14人を確保する。**主催者・協力者それぞれが「30〜40代独身の友人・同僚・元同僚」に個別に(一斉送信ではなくLINE個別で)声をかける。誘い文句はブランドブックのトーンそのままでいい——「新しいイベント立ち上げるんだけど、初回だから信頼できる人だけ呼んでる。来てくれない?」。**「あなただから呼んだ」という文脈は、無名イベント最強の集客コピー**です。
2. **女性から先に埋める。**女性の参加確定が取れてから男性枠を開ける。逆をやると当日男余りで初回が終わります。女性は「知人の紹介+参加確定済みの女性が既に◯人いる」という安心情報がないと動きません。紹介時に「女性はすでに◯人決まってる」と言えるようにする。
3. **初回の公募枠(6人)はPeatixかこくちーずで、種目名を主語に出す。**「【30代40代・1人参加限定】日曜昼のボードゲーム会 — 伴活 vol.1」。「出会い」と書かなくても、「30代40代限定・独身・1人参加」の3語で伝わる人には伝わります。ブランドの純潔を守りつつ実質を伝える、これが現実解です。
4. **初回参加費は男女とも3,000〜3,500円+「初回モニター価格」と明示。**無料は絶対にダメ(ドタキャン率が跳ね上がり、質も下がる)。「モニター」と言うことで、実績ゼロを「あなたは創業メンバー」という特権に変換できます。
5. **初回の隠れた最重要目的は「素材と証言の獲得」。**プロカメラマン(または撮れる友人)を入れ、写真掲載同意書を取り、当日の写真・参加者の感想コメントを回収する。**第1回の本当の商品は第2回の集客素材です。**
6. **解散前に第2回の日程を発表し、その場で先行申込を受ける。**「また会う口実はこちらで用意します」を実行で証明する唯一の方法。次回日程が未定のままの解散は、リピート率設計の放棄です。

### 4-2. 男女比への打ち手

- 申込フォームを男女別枠(各10名)で管理。片方が埋まったら「キャンセル待ち」。婚活パーティーの手法ですが、**見せ方だけ変えればブランドは汚れません**(「席の都合で男女それぞれ10名まで」)。
- 種目でバランスを取る:「料理×ボードゲーム」のように男女それぞれに引きのある要素を混ぜた複合種目にする。
- 崩れた場合の保険:開催3日前に比率が6:4を超えていたら、少ない側に主催者ネットワークから「サクラではなく本物の知人」を補充する体制を初回から用意しておく。

### 4-3. 「遊び目的お断り」に実効性を持たせる

- **申込時に本人確認(身分証)+簡単な事前アンケート**(参加動機を自由記述で書かせる。文章は嘘をつきにくい)。
- **主催者が全申込者と事前にLINEで1往復する。**手間ですが、20人規模なら可能。この一手間が「管理されている場」という安心を女性側に与え、遊び目的には「面倒な場」として自然に忌避されます。**スクリーニングとは審査ではなく、面倒くささの設計です。**
- 行動規範を当日冒頭に30秒で明言(「イベント外での連絡先の強要は退場・以後お断り」)+通報窓口(主催者LINE)を明示。
- 違反者は静かに出禁。ブラックリストは初回から運用する。

### 4-4. 価格設定

- **定価:男性4,500〜5,500円、女性3,500〜4,500円(食材・材料費込み)。**男女差は小さめに。差をつけすぎると「婚活の空気」になり、女性側も「客扱いされている」と感じてコンセプトが崩れます。
- 婚活パーティー(男6,000〜8,000円)より安く、オフ会(〜1,500円)より明確に高く。**「趣味コン価格帯の上限」が伴活のポジションに一致**します。
- 収支は初回赤字前提でいい。ただし「1回あたり最大いくらまで溶かすか」の上限は今すぐ決めること。

### 4-5. 「連絡先交換を迫らない」の再設計

「迫らない」は残し、「機会を奪わない」を足す。

- **イベント翌日、主催者経由の相互希望マッチングを導入する。**参加者は主催者LINEに「また会いたい人」を申告→相互一致した場合のみ、双方の同意を得て繋ぐ。片思いは相手に一切伝わらない。これなら「その場で迫られない安心」と「ちゃんと繋がれる希望」が両立し、しかも**「また会いたい人がいた率」というKPIがこの仕組みからそのまま計測できます**。運営コストほぼゼロで、ブランド哲学とも完全に整合する。やらない理由がありません。
- 次回イベントの先行案内を「再会の口実」として毎回セットで配る(4-1-6と同じ)。

### 4-6. 内輪化防止の運営手順化

- リピーターには申込時に「ホスト役(新規の人の隣に座り、輪に入れる係)」を明示的に依頼する。**常連を「客」から「準スタッフ」に変えるのが、内輪化防止の唯一の実証済み手法**です。理念で防げた例を私は知りません。
- 席・班は運営が指定し、毎回シャッフル。常連同士を同じ班にしない。
- 「初参加者が輪の外にいる時間ゼロ」は理念でなくチェックリストにする(受付で必ず一人つく/最初の班に必ず運営を入れる、等)。

### 4-7. 初期の種目選定

初回〜3回目は**「屋内・着席・道具が場を持たせる・雨天リスクなし」**の種目に絞る。具体的にはボードゲーム会か、調理済み食材を使う軽い料理会。焚き火と散歩はブランドの象徴として写真では使いつつ、実施は運営が回り始める5回目以降。**世界観の理想種目と、立ち上げ期の実務種目は分けて考える**こと。

## 5. ホームページに足りない情報

現状のHPはブランドサイトとしては良質ですが、**イベント集客ページとしては申込判断に必要な情報がほぼ全欠**です。30〜40代は慎重です。以下が無いページから申し込みは発生しません。

| 欠落情報 | 深刻度 | コメント |
| --- | --- | --- |
| **開催エリア** | ★★★ | 東京か大阪か地方か、一切書かれていない。訪問者は3秒で「自分に関係あるか」を判定して離脱する。最低限「まずは◯◯(都市名)で始めます」の一行を今すぐ入れるべき |
| **料金** | ★★★ | 価格未記載の出会い系イベントは「高額請求では」「マルチの入口では」という最悪の連想を招く。この年代は特にそこに敏感 |
| **主催者の顔と名前** | ★★★ | 実名・顔写真・「なぜ伴活を始めたか」のストーリー。無名ブランドの信頼はブランドではなく個人が担保する。ブランドストーリー(第1章)の名文は、語り手の顔があって初めて機能する |
| **次回イベントの具体情報** | ★★★ | 日時・場所・種目・定員・残枠。「準備中」の一行では登録動機が発生しない。日程が本当に未定なら「◯月に第1回を予定」だけでも書く |
| **安心・安全の具体策** | ★★☆ | 本人確認の有無、独身確認、トラブル時の対応、運営スタッフの常駐。「遊び目的お断り」を宣言するなら、その担保方法を書かないと空手形。特に女性の申込率に直結 |
| **当日の流れ** | ★★☆ | 受付→何をする→何時に終わる。初参加のハードルは「何が起きるか分からない不安」。タイムテーブルのサンプルだけで申込率は目に見えて変わる |
| **参加者の声・写真** | ★★☆ | 初回前は無いのが当然だが、初回後は最優先で掲載。それまでは主催者ストーリーで代替する |
| **男女比・独身確認の方針** | ★★☆ | 「30代・40代の独身の方が中心」だけでは弱い。既婚者が混ざる可能性への態度を明示しないと、この年代の女性は動かない |
| **運営者情報(特商法表記・会社/個人名・連絡先)** | ★★☆ | 有料イベントを売るなら法的にも必須。信頼性の土台 |
| **機能するCTA** | ★★★ | 「LINEで案内を受け取る」がリンク切れ(`href="#"`・準備中)。**サイトを公開しながら受け皿がないのは、集客上いちばんやってはいけない状態。**LINE開設が間に合わないなら、せめてメールアドレス登録フォーム(Googleフォームで十分)を今日置くべき |

## 最後に — 良い点は良いと言っておく

- **「間」の市場認識は正しい。**「婚活は重い、アプリは疲れた、でも不安」という30〜40代の感情の解像度は、業界人の私から見ても的確です。この層は実在し、既存サービスに本当に不満を持っています。
- **「恋愛はアリバイが必要」という洞察に(半ば無自覚に)到達している**のは大きい。「出会い目的で来る気まずさの除去」は、金を払う価値のある本物のインサイトです。
