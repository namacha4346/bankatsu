# 伴活 ブランドブック（Ver.1 ドラフト）

> このドキュメントは「伴活」というブランドの中心を定義するものです。
> イベントの企画、SNSの投稿、Webサイトの文章、ロゴのデザイン——
> すべての判断に迷ったとき、ここに戻ってくるための一冊です。

---

# 第1章 ブランドストーリー

## なぜ、伴活なのか

20代の頃、出会いは向こうからやってきた。

学校があった。部活があった。新しい職場があった。
友達が誰かを連れてきた。誰かの結婚式で隣に座った。

出会おうとしなくても、人生のほうが勝手に人を連れてきてくれた。

30代になると、それが静かに止まる。

仕事は面白くなり、責任は増え、
趣味は深まり、生活は安定して、
気づけば、会う人はいつも同じ顔ぶれになっている。

それは失敗ではない。怠慢でもない。
**ただ、人生がそういう構造になっているだけだ。**

なのに世の中は、この年代の独身者に二つの選択肢しか用意していない。

ひとつは、結婚を前提に条件を並べて面接のように向き合う「婚活」。
もうひとつは、写真とスペックで判断され、メッセージに疲れていく「アプリ」。

どちらも「出会い」を **目的** にしてしまった。
だから重くなるか、軽くなりすぎるか、どちらかになる。

私たちは思う。

**出会いは、目的にした瞬間につまらなくなる。**

いちばんいい出会いは、いつも何かの「ついで」に起きていた。
一緒に何かをして、笑って、また会って、
気づいたら隣にいた——それが自然な出会いの姿だった。

伴活は、その「自然な出会いが起きる場所」を、
大人になった私たちのために、もう一度つくる活動だ。

恋人を探しに来なくていい。
結婚を約束しに来なくていい。

ただ「なんか楽しそうだから」来てくれたらいい。

そこに、安心できる人がいて、
価値観の合う人がいて、
また会いたい人がいたなら——

人生を共に歩む「伴」は、
探すものではなく、**見つかってしまうもの** だから。

## ひとことで言うなら

> 出会いもある。でも、それだけじゃない。

# 第2章 ブランド哲学

伴活のすべての判断の根っこにある、5つの信念。

## 1. 恋愛は目的ではなく、結果である

出会いを目的にすると、人は相手を「候補」として見る。
候補として見られた人は、値踏みされたと感じる。
だから伴活は、恋愛を目的の席から下ろす。
一緒に楽しむことを目的にすれば、恋愛は結果としてついてくる。

**判断基準:** 企画や文章が「恋人を作らせよう」としていたら、それは伴活ではない。

## 2. 人柄は、プロフィールより先

年収・学歴・身長・肩書きは、その人が「何を持っているか」でしかない。
伴活が見たいのは「どんなふうに人と居る人か」。
笑い方、聞き方、店員さんへの態度、負けたときのリアクション。
プロフィール欄には書けないものこそが、人生を共に歩む相手を決める。

**判断基準:** スペックが先に見える設計(プロフィールカードの配布など)はしない。人柄が先に伝わる設計(一緒に体験する)をする。

## 3. 孤独に効くのは、恋人ではなく「伴」

私たちが解消したいのは「恋人がいない状態」ではない。
「この先の人生を、一人で抱え込む不安」だ。
それに効くのは、恋人とは限らない。
また会いたい人、気の合う仲間、大切な存在——それらを全部ひっくるめて「伴」と呼ぶ。
だから伴活は、恋人ができなかった夜も、収穫のある夜にできる。

**判断基準:** 「カップル成立数」を成果として誇らない。「また会いたい人がいた」を誇る。

## 4. 初めて来た人が、いちばん居心地いい場所にする

コミュニティは放っておくと内輪化する。常連が空気を作り、新規が客になる。
伴活は逆を設計する。**初参加がいちばん歓迎される場。**
常連はいていい。ただし常連の役割は「内輪を作ること」ではなく「新しい人を迎えること」。

**判断基準:** 初参加者が輪の外にいる時間が生まれる設計は、すべて失敗とみなす。

## 5. イベントは入口であって、ゴールではない

伴活のイベントは、それ自体が完成品ではない。
そこから始まる「また会う」「一緒にやる」「人生が広がる」のための入口だ。

**判断基準:** イベントの成功は当日の盛り上がりではなく、後日「また来たい」「また会いたい」が起きたかで測る。

# 第3章 ミッション・ビジョン・バリュー

## ミッション（果たす役割）

**30代・40代になっても、新しい出会いはある。という希望を届ける。**

## ビジョン（目指す景色）

**人生を共に歩める人との出会いを、もっと自然なものにする。**
そして「婚活」「就活」「終活」と並ぶ言葉として、「伴活」を社会に根づかせる。

## バリュー（行動原則）

1. **人柄がプロフィールより先** — 条件ではなく、人を見る
2. **出会いを急がない** — 恋愛は結果。まず人として知る
3. **初参加が一番居心地いい** — 毎回、新規が安心できる
4. **内輪を作らない** — 社会人サークル化しない
5. **イベントは入口** — 人生が広がるきっかけにする

# 第4章 ブランドパーソナリティ

伴活を「一人の人」だとしたら、どんな人か。
文章を書くとき、イベントで振る舞うとき、この人になりきる。

## 伴活は、こういう人

- **35〜40歳くらいの、聞き上手な友人。** 幹事をやらせたら天下一品
- 初対面の人を放っておけない。輪の外にいる人に自然に声をかける
- 恋バナを無理に振らない。でも相談されたら真剣に聞く
- 落ち着いているが、堅くない。よく笑う
- 誰かを値踏みする話(年収・スペック・モテ)には乗らない
- 「絶対いい人見つかるよ!」とは言わない。「まあ、来てみなよ」と言う

## 伴活は、こういう人ではない

- テンションで押してくる司会者
- 成婚実績を誇る結婚相談所のカウンセラー
- 恋愛テクニックを語るコーチ
- 内輪ノリで盛り上がるサークルの古株

## パーソナリティを表す5つの形容詞

**あたたかい / 自然体 / 誠実 / ほどよくユーモアがある / 押しつけない**

# 第5章 トーン&ボイス（言葉のガイドライン）

## 基本原則

1. **誘うのではなく、開いておく。**
   「ぜひご参加ください!」ではなく「よかったら、どうぞ」の距離感。
2. **断定して煽らない。**
   「必ず出会えます」「理想の相手が見つかる」は書かない。伴活は約束できないことを約束しない。
3. **恋愛を主語にしない。**
   主語は「楽しい時間」「いい人たち」「体験」。恋愛はいつも文の後ろのほうに、さりげなく。
4. **等身大で書く。**
   ビジネス敬語すぎず、タメ口すぎず。「友人からの誘いのLINE」がお手本。
5. **不安に寄り添うが、不安を煽らない。**
   「このままだと一生独身ですよ」のような恐怖訴求は絶対にしない。

## 使う言葉 / 使わない言葉

| 使う | 使わない |
| --- | --- |
| 伴、出会い、きっかけ | 恋活、婚活(自称として) |
| 人柄、価値観、居心地 | スペック、ハイスペ、条件 |
| また会いたい人 | 理想の相手、運命の人 |
| 一緒に楽しむ、体験する | アプローチ、アピール、狙う |
| 参加する人、来てくれた人 | 男性会員様、女性会員様 |
| 自然に、ゆっくり、そのうち | 今すぐ、ラストチャンス、駆け込み |
| 人生を共に歩む | 成婚、ゴールイン |

## 文章サンプル（Before → After）

**イベント告知**

- ❌ Before: 「30代40代限定婚活パーティー開催!真剣な出会いをお約束します!」
- ⭕ After: 「日曜の昼、みんなで◯◯します。初めての人ほど楽しめる会です。いい出会いがあるかは分かりませんが、いい時間になることは約束します。」

**参加後のフォロー**

- ❌ Before: 「気になるお相手とのマッチングは成立しましたか?次回イベントのご案内です!」
- ⭕ After: 「先日はありがとうございました。また会いたい人、いましたか? 次はこんな会をやります。気が向いたら、また。」

**ブランド紹介**

- ❌ Before: 「伴活は、成婚率にこだわる新しい婚活サービスです」
- ⭕ After: 「伴活は、人生を共に歩める“伴”と出会う活動です。恋人も、夫婦も、大切な仲間も。出会いもある。でも、それだけじゃない。」

# 第6章 世界観（ビジュアル・体験の方向性）

## キーワード

**「上質な普段着」**

特別な日ではなく、いい休日。
非日常ではなく、「いつもよりちょっといい日常」。

## 空気感の参照点

- Snow Peak — 自然体で、道具と体験に誠実。焚き火を囲む距離感
- Airbnb — 「泊まる」を「暮らすように旅する」に再定義した言葉の設計
- 無印良品 — 装飾を削ぎ、生活の言葉で語る態度
- ほとりのカフェ、昼の光、木のテーブル、歩きたくなる道

(※スタイルを真似るのではなく、「体験への誠実さ」を参照する)

## ビジュアルトーン

| する | しない |
| --- | --- |
| 自然光、昼〜夕方の光 | ネオン、パーティーの暗がり |
| 木、土、布などの質感 | 光沢、ラメ、ゴールド装飾 |
| 落ち着いた色(生成り、深緑、藍、テラコッタ) | ピンク×白の「婚活配色」 |
| 横に並んで歩く・座る構図 | 向かい合って見つめ合う構図 |
| 手元、後ろ姿、風景 | モデルの決め顔、カップル素材写真 |
| 余白の多いレイアウト | 情報を詰め込んだチラシ感 |

## モチーフの方向（ロゴ検討への引き継ぎ)

- **禁止:** ハート、指輪、鳥のつがい、教会、ブーケ
- **候補:** 並んで歩く二人の抽象化 / 縁(円) / 一本道 / 「伴」の字の抽象化
- 目指す到達点: Apple や Nike のように、**シンボルだけでブランドが分かる状態**
- 「伴」という字は「人」に「半」——**一人と一人が、半分ずつ持ち寄る**と読める。この解釈はロゴ・コピーの資産になりうる

# 第7章 ブランド体験の原則（イベント設計への引き継ぎ）

ブランドは言葉ではなく体験で記憶される。イベント設計(優先順位②)は、以下を満たすこと。

1. **「探しに来た感」を消す** — 会の目的は体験(料理、散歩、焚き火、ゲーム…)。出会いはその横に置く
2. **一人参加が標準** — 一人で来て、一人で楽しめて、一人で帰れる。それでも満足できる会
3. **人柄が先に見える仕掛け** — 自己紹介より先に、一緒に手を動かす時間を置く
4. **初参加者ファースト** — 運営と常連の最重要任務は「新しい人がいちばん楽しかった」と言って帰ること
5. **急がせない導線** — 連絡先交換を「その場で迫らない」設計。また会う口実(次回の会)をブランド側が用意する

---

# 第8章 KPIとブランドの約束

## 測るもの（最重要3指標）

1. **また参加したい率**
2. **また会いたい人がいた率**
3. **満足度**

## 参考として見るが、誇らないもの

- 交際数・結婚数(結果指標。広告や実績訴求の主役にしない)

## ブランドの約束（対外的に言い切っていいこと）

- いい時間になることは約束する
- 初めての人がいちばん歓迎されることは約束する
- 条件で値踏みされないことは約束する

## 約束しないこと

- 恋人ができること
- 結婚できること

# 第9章 タグライン候補（検討用）

現時点の第一候補はコンセプトそのまま:

> **出会いもある。でも、それだけじゃない。**

サブ候補(用途・トーン別):

1. 「人生を、一人で抱えなくていい。」 — 本質ニーズ直球。少し重めなのでWebの深い階層向き
2. 「恋人より先に、また会いたい人を。」 — バリューの言い換え。SNS向き
3. 「探さない出会い、はじめよう。」 — アンチテーゼ型。広告向き
4. 「30代からの出会いは、こっち。」 — カジュアル。イベント告知向き
5. 「伴と、歩こう。」 — 最短・シンボリック。ロゴ横のワードマーク向き
