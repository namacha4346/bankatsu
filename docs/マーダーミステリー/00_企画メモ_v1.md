## 2. なぜ戦隊モノが今回の条件に適合するか

1. **5人固定 = 戦隊の人数。** 色で役割が決まるためHOが短く済み、初対面でも演じやすい。
2. **「仲間を疑う」の劇的さが最初から最大値。** 絆が大前提のジャンルなので、
   その前提が壊れる構図そのものがドラマになる。
3. **叙述トリックの装置がジャンルのお約束として最初から揃っている。**
   現代日常で叙述トリックをやる際の最大の難所は
   「なぜキャラクターが誤認するのか」の理屈付けだが、戦隊にはこれが不要：
   - 変身中の認識（スーツ越し・バイザー越し）
   - スーツを着たら誰が誰か分からない
   - 基地システム・司令官という改竄されうる情報源
   - 記憶処理・洗脳
   - **代替わり**（本作が使う装置）

### 注意点

- 世界観説明が増える。**設定は共通ハンドアウト1枚に収まる量に絞る。**
  真相に絡まない設定（敵の出自など）は全部切る。
- トーンの振れ幅が大きいジャンル。シリアスとコメディを混ぜると事故る。
  → 本格ヒーローに決め切った。

## 3. 世界観の核

### 3-1. 戦隊の鉄の掟

> 戦士は互いの素顔・本名・私生活を、一切明かしてはならない。
> 呼び名は色のみ。任務中は常に変身状態。
> 一人が敵に捕らえられたとき、仲間と、その家族に累が及ばないようにするため。

### 3-2. 今日という日

> 三ヶ月前、宿敵は倒された。戦いは終わり、組織は解散する。
> 機密指定は解除された。
> **今日は、全員が初めて素顔で会う日。**

この設定が、C案の最大の穴を塞ぐ。
（穴＝「自己紹介で『三代目ブルーです』と言った瞬間にズレが解消してしまう」）

「素顔で会うのは今日が初めて」というシチュエーション自体が
感動的であり、同時に叙述トリックの土台になっている。
王道特撮のトーンとも完全に一致する。

## 4. 真相の構造

### 4-1. 全員が信じていること

> **「レッドだけは、二十年間ずっと同じ一人だった」**

四色は代替わりを重ねたが、レッドだけは初代から最後まで変わらなかった。
それが戦隊の誇りであり、伝説だった。

### 4-2. 実際

**レッドも三度代替わりしていた。**

素顔を見せない掟のせいで、誰も気づかなかった。
各自が語る「レッドとの思い出」は、それぞれ別人のレッドとの思い出。

> 「あなたの言う『レッド』って、誰？」——この一言がそのまま真相になる。

### 4-3. 事件

解散式の当日、**最後のレッド**が死体で発見される。

---

## 5. 前半 / 中間開示の切り分け（技術的な肝）

自己紹介フェーズで各自にレッドの思い出を語らせると、
ズレが0:20に露呈して後半が持たない。露呈を二段に分ける。

| | 語られる内容 | なぜ流せる / 流せないか |
|---|---|---|
| **前半** | レッドの**人柄**（優しかった / 厳しかった / 無口だった） | 食い違っても「二十年もいれば人は変わる」で流せる。**全員が納得して素通りする** |
| **中間開示** | レッドの**身体的特徴**（利き手・身長・古傷・声） | 人柄と違い絶対に流せない。**ここで卓が凍る** |

前半に撒いた違和感が、中間開示の一枚ですべて意味を持って回収される。

## 6. キャラクター構成（在籍期間の設計）

戦隊の歴史を20年（Y1〜Y20）とする。

| プレイヤー | 在籍 | その人が知っている「レッド」 |
|---|---|---|
| 初代ブルー | Y1〜Y6 | 初代のみ |
| 初代グリーン | Y1〜Y9 | 初代 ＋ 二代目（**交代を跨ぐ**） |
| 二代目イエロー | Y7〜Y14 | 初代の末期 ＋ 二代目 |
| 二代目ピンク | Y11〜Y18 | 二代目 ＋ 三代目（**交代を跨ぐ**） |
| 三代目ブルー | Y15〜Y20 | 二代目の末期 ＋ 三代目 |

真相のレッド交代：**初代 Y1〜Y8 / 二代目 Y9〜Y16 / 三代目 Y17〜Y20（＝被害者）**

### 設計意図

- **ブルーを2人（初代・三代目）入れている。**
  同じ色の異世代がいることで「ブルーがあの時こう言った」という証言が二重化し、
  混乱が自然に増幅される。
- **交代を跨いでいる2人（初代グリーン・二代目ピンク）が動機の源泉。**
  この2人は理屈上「レッドが変わった」ことに気づけたはず。
  なぜ気づかなかったのか。あるいは、気づいていて黙っていたのか。

## 7. タイムテーブル（約2時間）

| 時間 | フェーズ | 設計上の役割 |
|---|---|---|
| 0:00-0:10 | 導入・ルール説明 | **フェアネス宣言**（下記）をここで行う |
| 0:10-0:20 | HO黙読・自己紹介 | 色と世代を名乗る。素顔を見せ合う演出 |
| 0:20-0:50 | 第1議論（30分） | レッドの**人柄**が語られる。ズレは素通りされる |
| 0:35頃 | （保険）追加調査情報 | 議論が枯れた場合の投入用 |
| 0:50-1:00 | **中間開示** | レッドの**身体的特徴**。ここで卓が凍る |
| 1:00-1:30 | 第2議論（30分） | 全証言の再構築 |
| 1:30-1:40 | 投票 | |
| 1:40-2:00 | エンディング・真相開示 | 反転 |

### フェアネス宣言（必須・逐語）

> ハンドアウトに書かれているのは、あなたのキャラクターが
> 「そう認識している」ことです。客観的事実とは限りません。

この一文の有無で、真相開示時の反応が
「そんなの分かるわけない」から「そこを疑うべきだった」に変わる。

## 8. 密談なしの帰結（設計制約）

- 秘密は「バレたら即座に自分が犯人に見える」重さが必要。
  隠すか、全員の前で自白するかの二択しかないため。
- 情報が全員に同時共有されるので議論が速く進む。**放置すると30分で枯れる。**
  時間で開示する調査情報の段階投入が必須。
- 5人なので犯人1・無実4。**全員に「動機」と「機会」を必ず持たせる。**
