## 3. 世界観

### 3-1. 戦隊の鉄の掟

> 戦士は互いの素顔・本名・私生活を、一切明かしてはならない。
> 呼び名は色のみ。任務中は常に変身状態。
> 一人が敵に捕らえられたとき、仲間と、その家族に累が及ばないようにするため。

### 3-2. 掟の抜け穴（真相の鍵）

> **色を変えれば、別人になれる。**
> 引退したことにして別の色で戻れば、誰にも気づかれない。

### 3-3. アルゴスの刻印と戦士番号（推理の中核装置）

- 全戦士は入隊時、右腕内側に〈アルゴスの刻印〉を受ける
- 刻印には**入隊順の通し番号**が割り当てられる
- 基地の各扉はこの番号で認証され、**入室記録には番号だけが残る**
- **掟のため、誰も他人の番号を知らない。自己申告するしかない＝嘘がつける**
- **重要ルール：色を変えて継続した戦士には、新しい番号が振られない**

### 3-4. 今日という日

> 三ヶ月前、宿敵は倒された。戦いは終わり、組織は解散する。
> 機密指定は解除された。**今日は、全員が初めて素顔で会う日。**

### 3-5. 事件

解散式の当日、主催者である**三代目レッド**が中央司令室で死体となって発見される。
死に方は明らかに**怪人の攻撃によるもの**。つまり——

> **フェイスレスはまだ生きている。この場に、誰かに擬態して。**

議論はのんびりした犯人当てではなく、**緊急作戦会議**になる。

## 4. 推理の芯（最重要セクション）

### 4-1. 叙述トリックを「飾り」にしないための構造

叙述トリックの弱点は、真相開示で驚くだけの飾りになりがちなこと。
本作はこれを構造的に回避する。

```
「どの世代のレッドと戦ったか」の証言
        ↓ 突き合わせ
    各自の在籍期間が確定
        ↓ 在籍順 = 入隊順
      戦士番号が確定
        ↓ 照合
   現場の入室記録の番号 = 犯人
```

**世代のズレを解かないと、番号が計算できない。**
**トリックを解くことが、そのまま犯人を割り出すことになる。**

### 4-2. 勝敗を分ける一点 —— 欠番

番号の計算には穴が一つある。**色替えには新番号が振られない**（3-3）。

**初代グリーンは、Y9から二代目レッドを務めていた。** これは彼の秘密。

| | 番号計算 | 結果 |
|---|---|---|
| **彼が黙り通す** | 二代目レッドに独立した番号があると誤認 → 以降が1つ繰り下がる | **無実の二代目ピンクが犯人に見える → 誤爆エンド** |
| **彼が全員の前で告白する** | 欠番が解消され、以降が1つ繰り上がる | **真犯人が確定** |

> **このゲームの勝敗は、一人のプレイヤーが自分の秘密を全員の前で明かすかどうかにかかる。**
> 密談がないため、その告白は必ず卓の真ん中で、全員が見ている前で起きる。
> 「密談なし・全体議論のみ」という形式に対する、最大の着火点。

### 6-3. 真犯人

最も若く、最も同情され、最も疑われない人物。

> **怪人は、外から来なかった。二十年かけて、内側で育った。**
> **わたしたちは、二十年間、誰と戦っていたのか。**

## 8. タイムテーブル（約2時間）

| 時間 | フェーズ | 内容 |
|---|---|---|
| 0:00-0:10 | 導入・ルール説明 | **フェアネス宣言**（下記） |
| 0:10-0:20 | 素顔の対面・自己紹介 | 二十年で初めて素顔を見せ合う演出。色と世代を名乗る |
| 0:20-0:50 | **第1議論** | 記憶欠落の申告。戦士番号の自己申告。レッドの**人柄**が語られる |
| 0:35頃 | （保険）追加調査情報 | 議論が枯れた場合の投入用 |
| 0:50-1:00 | **中間開示** | ①検死結果 ②レッドの遺品メモ ③歴代レッドの**身体データ** → 「レッドは複数いた」／同時に**怪人役へ二枚目のHOを渡す** |
| 1:00-1:30 | **第2議論** | 在籍期間の再構築 → 番号の算出。欠番問題が浮上 |
| 1:30-1:40 | **変身 → 二段階投票** | ①誰が怪人か ②誰が撃つか |
| 1:40-2:00 | 最後の一撃・エンディング | 分岐（第9節） |

### フェアネス宣言（必須・逐語）

> ハンドアウトに書かれているのは、あなたのキャラクターが
> 「そう認識している」ことです。客観的事実とは限りません。

### 前半 / 中間開示の切り分け

| | 語られる内容 | なぜ流せる / 流せないか |
|---|---|---|
| **前半** | レッドの**人柄**（優しかった / 厳しかった / 無口だった） | 「二十年もいれば人は変わる」で流せる。全員が納得して素通りする |
| **中間開示** | レッドの**身体的特徴**（利き手・身長・古傷・声） | 絶対に流せない。**ここで卓が凍る** |

### 怪人役HO二枚制

- **一枚目（開始時）**：無実のキャラクターとして書かれている。本人も自覚がない
- **二枚目（中間開示時にGMが手渡す）**：
  > 「あなたが失っていた記憶が、戻る。——あなたが、殺した。」

前半は本気で無実を演じ、後半は嘘をつく。
**一人のプレイヤーの中で、ゲームの意味が途中で反転する。**

## 9. エンディング分岐

投票① 誰が怪人か／投票② 誰が撃つか の組み合わせで分岐。

| # | 条件 | 結末 |
|---|---|---|
| **A. 真実の一撃** | 三代目ブルーを正しく撃つ | フェイスレスは倒れる。だが宿主・南雲廉も死ぬ。**ビタースイートな勝利** |
| **B. 誤爆** | 別人を撃つ | 無実の仲間を自らの手で殺す。フェイスレスは逃げ、次の宿主へ移る。**バッドエンド** |
| **C. 撃たない** | 全員が引き金を拒否する | 誰も死なない。だがフェイスレスは去り、いつかまた戻ってくる。**含みを残すエンド** |

### 「誰が撃つか」による差分

- **三代目ブルー自身が撃ち手に選ばれた場合** — 自らを撃つか否かの選択が生じる
- **二代目ピンクが撃ち手の場合** — 兄を撃つことになるため、拒否（Cルート）の動機が最大化
- **初代ブルーが撃ち手の場合** — 真実を隠したまま幕を引ける唯一の立場

## 10. 密談なしの帰結（設計制約・実装時の注意）

- 秘密は「バレたら即座に自分が疑われる」重さが必要。
  隠すか、全員の前で自白するかの二択しかないため
- 情報が全員に同時共有されるので議論が速く進む。**放置すると30分で枯れる。**
  時間で開示する調査情報の段階投入が必須（0:35の保険カード）
- 5人なので怪人1・無実4。**全員に動機と機会を持たせる**（記憶欠落で担保済み）
