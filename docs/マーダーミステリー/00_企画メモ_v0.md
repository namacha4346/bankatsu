## 2. 条件から導かれる設計指針

### 2-1. 「密談なし」× 「叙述トリック」は相性が良い

密談ありの場合、認識のズレに気づくのは当事者2人だけで終わる。
全体議論のみであれば、各自が自分の認識を全員の前で語るため、
**ズレが卓の中央で露呈する。**

> 「待って、あなたが言っている『あの夜』はいつの話？」

この瞬間を作ることが本作の設計上の中心。すべてここから逆算する。

### 2-2. 密談なしの帰結

- 秘密は「バレたら即座に自分が犯人に見える」重さが必要。
  隠すか、全員の前で自白するかの二択しかないため。
- 情報が全員に同時共有されるので議論の進みが速い。
  **放置すると30分で枯れる。** 時間で開示する調査情報の段階投入が必須。

### 2-3. 4〜5人の帰結

- 犯人1・無実3〜4。**全員に「動機」と「機会」を必ず持たせる。**
  でないと序盤で容疑者が2人に絞れて終わる。

### 2-4. 叙述トリックのフェアネス原則（最重要）

「プレイヤーが騙される」構造にすると理不尽になる。
**「キャラクターが誤解している」構造にする。**

冒頭のルール説明で必ず以下を宣言する：

> ハンドアウトに書かれているのは、あなたのキャラクターが
> 「そう認識している」ことです。客観的事実とは限りません。

この一文の有無で、真相開示時の反応が
「そんなの分かるわけない」から「そこを疑うべきだった」に変わる。

## 3. タイムテーブル（骨格・約2時間）

| 時間 | フェーズ | 設計上の役割 |
|---|---|---|
| 0:00-0:10 | 導入・ルール説明 | フェアネス宣言をここで行う |
| 0:10-0:20 | HO黙読・自己紹介 | 公開情報のみ名乗る |
| 0:20-0:50 | 第1議論（30分） | 全員が共通の前提で推理。ズレには誰も気づかない |
| 0:35頃 | （保険）追加調査情報 | 議論が枯れた場合の投入用 |
| 0:50-1:00 | 中間開示 | 前提を1つ壊す物証。違和感の種を撒く |
| 1:00-1:30 | 第2議論（30分） | ズレの再検証。理想的にはここで卓が気づく |
| 1:30-1:40 | 投票 | |
| 1:40-2:00 | エンディング・真相開示 | 反転 |

## 4. プロット案（検討中）

### A案「十年目の答え合わせ」— 時間のズレ ★推奨

- **舞台**：貸切バー。高校の同級生5人が、10年前に死んだ同級生Kを偲んで集まる
- **事件**：幹事が「今日、Kの死の真相を話す」と言って席を立ち、死体で発見される
- **トリック**：各HOには「自分がKと最後に会った夜」の回想がある。
  全員が「自分が最後にKに会った人間だ」と思い込んでいるが、
  Kは死の直前の数日間、5人と個別に会っていた。
  「Kと最後に会った人物が怪しい」という議論の前提そのものが崩れる。
- **評価**：反転が一発で明快。日常的で演技のハードルが低い。
  動機も全員に自然に配れる（Kに言った / 言わなかったことへの罪悪感）。
  自作1本目として最も破綻しにくい。

### B案「送信者不明」— 人物のズレ

- **舞台**：シェアハウス。住人の1人が階段から転落死
- **トリック**：全員が「亡くなる直前に本人からメッセージをもらった」と証言するが、
  そのアカウントを使っていたのが本人とは限らない。「あの人」が別人だった型
- **評価**：現代的で刺さりやすいが、スマホ画面の小道具作り込みが必要で制作コスト高

### C案「この家の子」— 立場のズレ

- **舞台**：父の四十九日、実家。相続をめぐる兄弟姉妹
- **トリック**：誰が本当の子なのか、という自己認識がひっくり返る
- **評価**：情感は最も強いが、推理より人間ドラマ寄りになる。
  身内で気軽に遊ぶには題材が重い
