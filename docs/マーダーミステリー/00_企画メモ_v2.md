# 自作マーダーミステリー 企画メモ Ver.2

> 仮題：**「わたしたちのレッド」** / 別案「最後の変身」「二十年目の素顔」

---

## 0. Ver.1 からの変更理由（重要）

Ver.1 の設計は **「戦隊の衣装を着せただけの、普通のマダミス」** だった。
事件を現代日常の同窓会に置き換えてもトリックがそのまま成立してしまい、
戦隊モノを選んだ意味がなかった。

**根本原因**：マダミスは「座って話す」ゲーム、戦隊は「立って戦う」ジャンル。
この矛盾を放置したまま設定だけ戦隊にしたので、ヒーロー要素が飾りになった。

**解決の方針**：**議論すること自体をヒーローの行為にする。**
共通目的「怪人を倒す」を game の軸に据え、そこに各自の思惑を交差させる。

## 2. 世界観の核

### 2-1. 戦隊の鉄の掟

> 戦士は互いの素顔・本名・私生活を、一切明かしてはならない。
> 呼び名は色のみ。任務中は常に変身状態。
> 一人が敵に捕らえられたとき、仲間と、その家族に累が及ばないようにするため。

### 2-2. 掟の抜け穴（真相の鍵）

> **色を変えれば、別人になれる。**
> 引退したことにして別の色で戻れば、誰にも気づかれない。

これが怪人の侵入経路であり、同時に卓上の誰かが隠している秘密でもある。

### 2-3. 今日という日

> 三ヶ月前、宿敵は倒された。戦いは終わり、組織は解散する。
> 機密指定は解除された。今日は、全員が初めて素顔で会う日。

### 2-4. 事件

解散式の当日、**最後のレッド（三代目）**が死体で発見される。
死に方は明らかに**怪人の攻撃によるもの**。つまり——

> **怪人はまだ生きている。この場に、誰かに擬態して。**

議論の性質がここで変わる。のんびりした犯人当てではなく、**緊急作戦会議**。

---

## 3. 三つの中核メカニクス

### 3-1. 二段階投票 —— 投票の意味を変える

エンディング直前、5人は変身し、怪人と対峙する。怪人は仲間の姿をしている。

1. **誰が怪人か**
2. **誰が最後の一撃を撃つか**

間違えれば、仲間を自らの手で殺すことになる。
犯人当てではなく **「誰を信じ、誰に引き金を託すか」** という選択になる。
1の判断が推理、2の判断が思惑の交差点。

### 3-2. 全員の記憶欠落 —— 密談なしを武器に変える

怪人の擬態は記憶ごと乗っ取るため、擬態された本人にも自覚がない。
そこで **5人全員のHOに、記憶が欠けている時間帯を書く。**

> 「あなたは、◯時◯分から◯時◯分までの記憶がない。」

- 全員が「まさか自分が？」を抱えたままプレイする
- 密談がないので、**その欠落を全員の前で申告するかどうか**が最大の緊張になる。
  黙れば疑われないが、後でバレたら終わり
- 推理の骨格は **欠落時間帯がそれぞれ違うこと**。
  証言と物証を突き合わせれば犯行可能な人物は論理的に絞れる

「絆」を看板にしたジャンルで、**自分自身すら信じられない**。テーマが一本通る。

### 3-3. 世代のズレを事件と一本化する

Ver.1 の弱点：「レッドが代替わりしていた」という歴史の謎が、
今日の事件と繋がっていなかった。ここを接続する。

> **「代替わり」こそが、怪人の侵入経路だった。**

素顔を明かさない掟の下では、誰かが引退するたび、その後任に怪人が入り込む余地があった。
レッドが三度代わっていたという事実の発覚は、そのまま次の問いに直結する。

> **「じゃあ、他の色は？ わたしたちは本当に、二十年間ずっと仲間だったのか？」**

## 4. 前半 / 中間開示の切り分け（技術的な肝）

自己紹介で各自にレッドの思い出を語らせると、ズレが0:20に露呈して後半が持たない。
露呈を二段に分ける。

| | 語られる内容 | なぜ流せる / 流せないか |
|---|---|---|
| **前半** | レッドの**人柄**（優しかった / 厳しかった / 無口だった） | 食い違っても「二十年もいれば人は変わる」で流せる。全員が納得して素通りする |
| **中間開示** | レッドの**身体的特徴**（利き手・身長・古傷・声） | 絶対に流せない。**ここで卓が凍る** |

さらに本作では、中間開示が **アリバイ表の全面組み直し** を強制する。
証言の時系列が組み替わるため、前半で作ったアリバイが無効になる。

## 5. キャラクター構成

### 5-1. 在籍期間（戦隊の歴史20年 = Y1〜Y20）

| プレイヤー | 在籍 | 知っている「レッド」 |
|---|---|---|
| 初代ブルー | Y1〜Y6 | 初代のみ |
| 初代グリーン | Y1〜Y9 | 初代 ＋ 二代目（**交代を跨ぐ**） |
| 二代目イエロー | Y7〜Y14 | 初代の末期 ＋ 二代目 |
| 二代目ピンク | Y11〜Y18 | 二代目 ＋ 三代目（**交代を跨ぐ**） |
| 三代目ブルー | Y15〜Y20 | 二代目の末期 ＋ 三代目 |

真相のレッド交代：**初代 Y1〜Y8 / 二代目 Y9〜Y16 / 三代目 Y17〜Y20（＝被害者）**

**ブルーを2人（初代・三代目）入れている**のは、
「ブルーがあの時こう言った」という証言を二重化して混乱を自然に増幅させるため。

### 5-2. 表の立場と裏の思惑

| | 表の立場 | 裏の思惑 |
|---|---|---|
| 初代ブルー | 最古参。式典の主催 | 戦隊の名誉を守りたい。「レッドは一人ではなかった」を絶対に公にさせない |
| 初代グリーン | 交代を跨いだ古参 | **かつて二代目レッドを務めていた**（色を変えて継続した）。初代レッドの死の真相を知っている |
| 二代目イエロー | 中期の主力 | レッドを継ぎたかった。選ばれなかった理由を知りたい |
| 二代目ピンク | 交代を跨いだ中堅 | 怪人の中に行方不明の肉親がいると信じている。**倒してほしくない** |
| 三代目ブルー | 最後のブルー。若手 | 死んだレッドの相棒。組織も歴史もどうでもいい。**彼を殺した奴だけが知りたい** |

「怪人を倒す」という共通目的は全員一致しているが、
**倒したくない人がいて、真実を隠したい人がいて、真実だけが欲しい人がいる。**
全体議論のみという形式で、この5つの思惑が卓の真ん中で正面衝突する。

## 6. タイムテーブル（約2時間）

| 時間 | フェーズ | 設計上の役割 |
|---|---|---|
| 0:00-0:10 | 導入・ルール説明 | **フェアネス宣言**（下記） |
| 0:10-0:20 | 素顔の対面・自己紹介 | 二十年で初めて素顔を見せ合う演出 |
| 0:20-0:50 | 第1議論（30分） | 記憶欠落の申告とアリバイ構築（全員が「レッドは一人」前提） |
| 0:35頃 | （保険）追加調査情報 | 議論が枯れた場合の投入用 |
| 0:50-1:00 | **中間開示** | レッドの身体的特徴の矛盾 → レッドは複数いた |
| 1:00-1:30 | 第2議論（30分） | 前提が崩壊。アリバイ表を全部組み直す |
| 1:30-1:40 | **変身 → 二段階投票** | 誰が怪人か / 誰が撃つか |
| 1:40-2:00 | 最後の一撃・エンディング | 反転と着地 |

### フェアネス宣言（必須・逐語）

> ハンドアウトに書かれているのは、あなたのキャラクターが
> 「そう認識している」ことです。客観的事実とは限りません。

## 7. 密談なしの帰結（設計制約）

- 秘密は「バレたら即座に自分が疑われる」重さが必要。
  隠すか、全員の前で自白するかの二択しかないため。
- 情報が全員に同時共有されるので議論が速く進む。**放置すると30分で枯れる。**
  時間で開示する調査情報の段階投入が必須。
- 5人なので怪人1・無実4。**全員に「動機」と「機会」を必ず持たせる。**
